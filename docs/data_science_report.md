## 1. Dataset

A synthetic Ghana / West-Africa grid dataset generated by a single seeded
script: **10 utilities**, **44 substations** (10 Ghanaian regions + 8
cross-border nodes), **55 lines** (40 overhead / 15 underground). Voltage
levels 11 / 33 / 69 / 161 / 330 kV. It is grounded in real geography and real
utility names (ECG, NEDCo, GRIDCo, VRA) but every coordinate, capacity,
commissioning year and connection is illustrative — nothing here is an official
measurement of Ghana's grid.

## 2. Cleaning and validation (Task 1)

The generator emits clean data, so the value of this step is the *validation
code*, not the (empty) defect list. We:

- coerced Latitude, Longitude, Capacity (MVA) and Length (km) to numeric
  (`errors='coerce'`);
- checked missing values per column (none) and full-row duplicates (none);
- validated every coordinate against West African bounds (all pass);
- validated **foreign keys**: every source/destination substation ID in
  `lines.csv` exists in `substations.csv`; every `Utility ID` exists in
  `utilities.csv` — **0 orphaned references**;
- checked categorical columns (Status, Type, Line Type) against allowed sets.

**Outcome:** 0 rows dropped, 0 imputations. For real asset registers we would
expect gaps and would impute (region → mode, capacity → voltage-class median)
and log every change; that policy is documented in
`cleaned_data/data_cleaning_report.md`.

## 4. Integration and merged-data insights (Task 4)

A left join on `Utility ID` and the two substation foreign keys yields a
55-row master line table (`integrated_data/master_lines.csv`, 28 columns). Row
count is unchanged (55 → 55) with 0 unmatched keys — referential integrity
confirmed. New insights only visible after the merge:

- **GRIDCo** carries the most rated transfer capacity (~6,040 MVA across its 24
  lines) — expected for the transmission backbone.
- Inter-regional corridors are sparse: most region pairs are joined by a
  single line, so nearly every backbone line is a structural single point of
  failure.
- 4 cross-border lines model WAPP interconnections (Ghana↔Burkina Faso,
  ↔Côte d'Ivoire, ↔Togo, Togo↔Benin); all are bridges.

## 5. Network analysis (Task 2 & Task 5)

Undirected graph: 44 nodes, 55 edges. **3 connected components** (a 41-node
giant component + 2 isolated substations) — building the graph from IDs rather
than names is what makes the isolates visible.

- **Centrality.** Highest betweenness (length-weighted): Cape Coast 0.526,
  Takoradi 0.516, Kumasi Central 0.501, Koforidua 0.498 — the substations on
  the single north–south / east–west corridors.
- **Communities.** Greedy modularity finds 10 communities that track
  administrative regions and cross-border clusters.
- **Bridges / efficiency.** 21 of 55 edges are bridges. Global efficiency
  0.244; length-weighted average shortest path ≈ 819 km — a long, thin,
  lightly meshed topology.

### N-1 contingency

- **Substation loss:** removing **Kumasi Central** is worst — 3 extra
  fragments, 15 substations cut from the giant component. Cape Coast / Takoradi
  cut ~20 each into 2 fragments. Peripheral Greater Accra substations (Mallam,
  Legon) cause no extra fragmentation.
- **Line loss:** **21 of 55** single-line failures split the network — exactly
  the bridge set.

**Conclusion:** this synthetic grid is radial-leaning and **not topologically
N-1 secure**. The actionable recommendation is to add loop connections around
the identified bridge corridors (Kumasi–coast, Sunyani–north, the cross-border
tails). This is a graph-topology approximation only — it ignores load flow,
thermal limits, voltage stability and protection coordination.

## 7. Challenges

1. **Wrong first hypothesis.** We expected a meshed network resilient to N-1;
   the data disagreed. We kept and explained the finding.
2. **Multi-component graph.** The brief's name-keyed snippet hides isolates;
   switching to ID keys exposed 3 components and forced every downstream metric
   (efficiency, average path length) to be scoped to the giant component.
3. **Responsible framing.** Every metric is labelled a *structural* proxy, and
   the report repeatedly states the data is synthetic — the temptation is to
   present centrality rankings as operational truth.
4. **Reproducibility.** Keeping `random.seed(42)` untouched and writing a
   report from every script means any grader re-running the pipeline gets
   byte-identical CSVs and the same numbers quoted here.
