# Data Dictionary — National Electricity Grid Network Analysis

Covers the three cleaned source datasets (`cleaned_data/*_clean.csv`, produced by
`task1_data_cleaning.py`) and the merged dataset (`integrated_data/merged_lines.csv`,
produced by `task1b_data_integration.py`).

All three source datasets are generated by `Datasets/generate_grid_data.py` with
`random.seed(42)`. Coordinates, capacities, commissioning years and connections are
synthetic and illustrative — not real measurements of Ghana's or West Africa's
actual electricity infrastructure.

## utilities_clean.csv

| Field | Type | Description |
|---|---|---|
| Utility ID | integer | Unique identifier. Primary key. |
| Name | text | Full legal name of the utility. |
| Alias | text | Common short name (e.g. ECG, GRIDCo). |
| Code | text | Three-letter code used to reference the utility elsewhere (e.g. in `merged_lines.csv`). |
| Type | categorical | `Generation`, `Transmission`, or `Distribution`. |
| Country | text | Country (or countries) of operation. |
| Active | categorical | `Y` / `N` — whether the utility is currently operating. |

## substations_clean.csv

| Field | Type | Description |
|---|---|---|
| Substation ID | integer | Unique identifier. Primary key. Referenced by `lines_clean.csv` as Source/Destination Substation ID. |
| Name | text | Full substation name. |
| Short Name | text | Place name, used for labelling on maps/graphs. |
| Region | text | Administrative region (or bordering country, for cross-border nodes). |
| Country | text | Country. |
| Latitude | float | Decimal-degree latitude. Validated to fall within a West-African bounding box (see `data_cleaning_report.md` §8). |
| Longitude | float | Decimal-degree longitude. Same validation as Latitude. |
| Voltage (kV) | integer | Nominal operating voltage: one of 11, 33, 69, 161, 330. |
| Capacity (MVA) | float | Rated capacity in megavolt-amperes. Always > 0 (validated). |
| Commissioning Year | integer | Year the substation was notionally commissioned. |
| Type | categorical | `Distribution`, `Bulk Supply Point`, or `Transmission`. |
| Status | categorical | `Active` or `Inactive`. |

## lines_clean.csv

| Field | Type | Description |
|---|---|---|
| Line ID | integer | Unique identifier. Primary key. |
| Utility ID | integer | Foreign key → `utilities_clean.csv.Utility ID`. Which utility owns/operates the line. |
| Source Substation ID | integer | Foreign key → `substations_clean.csv.Substation ID`. One end of the line. |
| Source Substation | text | Denormalized source substation name (redundant with the ID lookup; validated to agree with `substations_clean.csv` — see cleaning report §7). |
| Destination Substation ID | integer | Foreign key → `substations_clean.csv.Substation ID`. Other end of the line. |
| Destination Substation | text | Denormalized destination substation name, same validation as above. |
| Voltage (kV) | integer | Operating voltage of the line. |
| Length (km) | float | Approximate line length, derived from source/destination coordinates. Always > 0 (validated). |
| Capacity (MVA) | float | Rated transfer capacity. Always > 0 (validated). |
| Status | categorical | `Active` or `Under Maintenance`. |
| Line Type | categorical | `Overhead` or `Underground`. |

Relationship note: the grid is modelled as an undirected graph (see `task2_networkx_graph.py`)
— "Source"/"Destination" reflect how the row was recorded, not a fixed direction of power flow.

## integrated_data/merged_lines.csv

One row per line (55 rows), joining `lines_clean.csv` with both endpoint substations and
the operating utility. Produced by a left join on `Source Substation ID`, `Destination
Substation ID`, and `Utility ID` — see `task1b_data_integration.py` and
`integrated_data/integration_report.md` for the join validation (0 unmatched rows).

| Field | Description |
|---|---|
| Line ID, Utility ID, Source/Destination Substation ID, Source/Destination Substation, Voltage (kV), Length (km), Capacity (MVA), Status, Line Type | Carried over unchanged from `lines_clean.csv`. |
| Source Name, Source Region, Source Country, Source Voltage (kV), Source Capacity (MVA), Source Status | Attributes of the source substation, joined from `substations_clean.csv`. |
| Destination Name, Destination Region, Destination Country, Destination Voltage (kV), Destination Capacity (MVA), Destination Status | Attributes of the destination substation, joined from `substations_clean.csv`. |
| Utility Name, Utility Alias, Utility Code, Utility Type, Utility Country | Attributes of the operating utility, joined from `utilities_clean.csv`. |

## network_analysis/network_metrics.csv

One row per substation (44 rows), produced by `task2_networkx_graph.py`.

| Field | Description |
|---|---|
| Substation ID, Name, Region | Identifying columns, carried over from `substations_clean.csv`. |
| Degree | Number of lines connected to this substation. |
| Degree Centrality | Degree normalized by network size. |
| Betweenness Centrality | Fraction of shortest paths (weighted by line length) passing through this substation. |
| Closeness Centrality | Inverse of average shortest-path distance to all other reachable substations. |
| PageRank | Random-walk importance score (weighted by line capacity). |
| Clustering Coefficient | How interconnected this substation's immediate neighbours are. |

All metrics are graph-structural measures on synthetic data — see
`network_analysis/network_analysis_report.md` §5 for interpretation caveats.
